# پورتفولیوی تعاملی یاس دستان

یک تجربهٔ تعاملی فارسی (RTL) برای نمایش کار یاس دستان: استراتژیست محتوا، کپی‌رایتر و طراح تجربه.

سایت به‌جای توضیح دادن مهارت، آن را اجرا می‌کند: ورودی صفحه یک میز کار شلوغ است و بازدیدکننده با حرکت نشانگر، تکه‌های پراکندهٔ کار را به یک ساختار تبدیل می‌کند.

## اجرا

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # خروجی در dist/
npm run preview  # پیش‌نمایش خروجی build
```

نیازی به هیچ سرویس پولی یا کلید API نیست.

## انتشار روی GitHub Pages

دو راه وجود دارد.

**۱. خودکار (پیشنهادی).** فایل `.github/workflows/deploy.yml` آماده است.

1. مخزن را روی GitHub بسازید و کد را روی شاخهٔ `main` پوش کنید.
2. در `Settings › Pages`، گزینهٔ **Source** را روی `GitHub Actions` بگذارید.
3. هر پوش روی `main` سایت را منتشر می‌کند.

**۲. دستی.**

```bash
npm run build
npx gh-pages -d dist   # یا محتوای dist را روی شاخهٔ gh-pages بگذارید
```

`base` در `vite.config.js` روی `'./'` تنظیم شده، بنابراین هم روی `username.github.io/repo/` و هم روی دامنهٔ اختصاصی بدون تغییر کار می‌کند.

## به‌روزرسانی سایتِ منتشرشده (جایگزینی فایل‌ها)

اگر نسخهٔ قبلی روی GitHub Pages است و می‌خواهید همین نسخه را جایگزین کنید:

1. کل پوشهٔ `src/`، فایل `index.html` و پوشهٔ `public/assets/` را با نسخهٔ جدید جایگزین کنید (فایل‌های تازه: `src/components/ContactForm.jsx`، `src/components/worlds/ChainReaction.jsx`، `public/assets/images/og-cover.jpg`، ویدیوی `public/assets/images/video/lego-teaser.mp4`).
2. `npm install` و بعد `npm run build`.
3. اگر انتشار خودکار دارید فقط `git add -A && git commit -m "chain reaction + contact form" && git push`؛ اگر دستی منتشر می‌کنید، محتوای `dist/` را روی شاخهٔ `gh-pages` بگذارید.
4. بعد از انتشار، در `index.html` مسیر تصویر `og:image` را به آدرس کامل `https://…/assets/images/og-cover.jpg` تغییر بدهید و `og:url` را اضافه کنید تا پیش‌نمایش لینک در شبکه‌های اجتماعی درست بیاید.

## فرم تماس

فرم پایین صفحه به Formspree وصل است (`https://formspree.io/f/mljdeegg`). آدرس در `src/data/content.js` داخل `contact.form.endpoint` است.

- ارسال با `fetch` انجام می‌شود، پس بازدیدکننده از صفحه بیرون نمی‌رود و پیام «رسید» را همان‌جا می‌بیند.
- فیلد پنهان `_gotcha` تلهٔ ربات است.
- فهرست نقش‌ها در `contact.form.roles` است؛ همان نام کارهایی که در پروژه‌ها آمده، پس اولین پیام از ابتدا موضوع دارد.
- ایمیل و شمارهٔ تماس یک‌جا در `CONTACT_EMAIL` و `CONTACT_PHONE` همان فایل تعریف شده‌اند و همهٔ دکمه‌ها از همان‌ها استفاده می‌کنند.

## دسترس‌پذیری و ریسپانسیو

- کامل RTL با فونت‌های فارسی پروژه
- هر تعامل نشانگر، معادل کلیک/کیبورد دارد
- `prefers-reduced-motion` رعایت شده
- موبایل: تعداد کاغذها کمتر و در یک سینی بالای صفحه؛ ستون‌ها تک‌ستونه می‌شوند؛ زنجیرهٔ «واکنش زنجیره‌ای» چندسطری می‌شود و خط اتصال حذف می‌شود
- قاعدهٔ راست‌به‌چپ: هر رشتهٔ لاتین داخل جملهٔ فارسی با `<T>` در `src/utils/Bidi.jsx` جداسازی می‌شود تا علامت‌ها و عددها جابه‌جا نشوند؛ بلوک‌هایی که کل محتوایشان انگلیسی است (مثل تگ‌لاین و کهن‌الگوهای LORE) با کلاس‌های `.en-block` و `.ltr-edge` چپ‌به‌راست ولی چسبیده به لبهٔ راست چیده می‌شوند

## قاعدهٔ محتوا

همهٔ اعداد، عنوان‌ها و نقل‌قول‌ها از فایل‌های واقعی پروژه آمده‌اند: گزارش محتوا، اسکرین‌شات‌های پنل اینستاگرام، سناریوها، بریف کاتالوگ مهرایان، سند کادک، گزارش رتبهٔ سئو و پروتوتایپ‌های فیگما. هرجا اطلاعات تأییدشده نبوده، به‌جای حدس زدن، در کد کامنت `// add verified …` گذاشته شده است.

## کارهای باقی‌مانده

- فایل `yas-dastan-portfolio.pdf` را در پوشهٔ `public/` بگذارید تا دکمهٔ «دانلود نسخه PDF» کار کند.
- ایمیل واقعی را در `src/data/content.js` جای `hello@example.com` بگذارید (دو مورد: هیرو و تماس).
- لینک اینستاگرام و لینکدین شخصی را در بخش `contact.channels` اضافه کنید.
- اگر عکس پشت‌صحنه یا ساخت جهان لگویی «واکنش زنجیره‌ای» دارید، در `public/assets/images/proof/` بگذارید و در `chain` (فایل `src/data/projects.js`) اضافه کنید؛ فعلاً کامنت `// add verified behind-the-scenes photos` آنجاست.
- نتیجهٔ تجاری کمپین رویداد مهرایان هنوز باز است و عمداً هیچ عددی برایش نوشته نشده.
